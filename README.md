# datablist-end-to-end-data-analysis
End-to-end analysis of five Datablist datasets using Python and Google Colab, covering data cleaning, duplicate analysis, data matching, and business insights.

# End-to-End Data Analysis Using Google Colab

## Project Overview
This project analyzes five datasets from Datablist
using Python, pandas, and Google Colab.

## Datasets
- Customers
- People
- Organizations
- Leads
- Products

Each dataset contains approximately 100,000 records.

## Project Steps
1. Data loading and inspection
2. Data cleaning and missing-value checks
3. Duplicate analysis
4. Common-column identification
5. Matching and merging checks
6. Statistical and business analysis
7. Business questions and answers
8. Final observations and recommendations

## Tools Used
- Python
- Google Colab
- pandas
- Excel

## Project Files
- Datablist_End_to_End_Analysis.ipynb
- Final_Data_Analysis_Report.xlsx

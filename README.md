# 👋 Hi there! Welcome to My Data Analysis Project

I'm excited to share my end-to-end data analysis project, where I explored real-world-style datasets, worked on data quality, and used Python to discover meaningful patterns and business insights.

## 📌 About the Project

The goal of this project was to understand how raw data can be cleaned, explored, compared, and transformed into useful information for business decisions.

I used five Datablist sample datasets, each containing 100,000 records, giving me approximately **500,000 records to analyze**.

## 📂 Datasets Used

- **Customers** — customer information and subscription details
- **People** — personal and professional information
- **Organizations** — company profiles and business attributes
- **Leads** — sales leads and company information
- **Products** — product prices, categories, stock, and availability

## 🔍 What I Worked On

- **Data inspection:** Checked dataset sizes, columns, and data types.
- **Data cleaning:** Checked missing values, extra spaces, and data consistency.
- **Duplicate analysis:** Investigated exact duplicate rows and repeated identifiers or contact details.
- **Common-data analysis:** Compared datasets to identify shared columns and matching values.
- **Data matching and merging:** Tested potential relationships between datasets and identified cases where matching values needed further validation.
- **Statistical analysis:** Examined customer distributions, job titles, industries, product prices, stock levels, and availability.
- **Business questions:** Used the analysis to answer practical questions and document the findings.
- **Final reporting:** Organized results, observations, and recommendations into an Excel report.

## 🛠️ Tools Used

- Python
- Google Colab
- pandas
- Excel
- GitHub

## 📊 Key Learnings

This project helped me understand that data analysis involves more than calculating totals and averages. Data quality, duplicate checking, and validating relationships between datasets are essential before drawing conclusions.

I also learned that columns with similar names or repeated values do not always guarantee a reliable match. Checking those relationships carefully helps prevent misleading results.

## 📁 Project Files

- **Google Colab Notebook (`.ipynb`)** — code and analysis workflow
- **Excel Analysis Report (`.xlsx`)** — data quality results, matching checks, business questions, and observations

## ▶️ How to Explore the Project

1. Open the Google Colab notebook to review the analysis code.
2. Review the saved outputs and follow the steps from data loading through final analysis.
3. Open the Excel report to explore the results and observations.

To rerun the notebook, upload the required CSV files into a Google Colab session and execute the cells in order.
